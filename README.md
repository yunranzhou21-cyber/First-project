# 健身追踪 (Gym Tracker)

一个纯前端、单文件的健身记录工具。用于记录每天的健身训练与体重变化。

## 功能特性

- 📅 **训练日历**：按月份浏览日历，点击任意日期记录当天训练

  - 标记是否为训练日

  - 选择当天锻炼的身体部位（胸 / 背 / 肩 / 手臂 / 腿 / 核心 / 有氧 / 全身，可多选）

  - 记录当天是否喝了蛋白粉

  - 日历上直接显示部位与蛋白粉文字标签

- ⚖️ **体重跟踪**：任选日期记录体重，自动生成体重变化趋势折线图

- 🌙 **深色主题**：默认深色界面，侧边栏导航切换功能

## 技术特点

- **单文件应用**：所有 HTML / CSS / JS 都整合在一个 HTML 文件中

- **离线可用**：无任何外部依赖，双击即可在浏览器中运行

- **数据本地存储**：所有数据保存在浏览器 `localStorage` 中，不会上传到服务器

- **初始无数据**：首次打开为空，数据完全由用户自己添加

## 使用方法

1. 使用浏览器直接打开 `gym-tracker.html`
2. 在 **训练日历** 中点击日期，填写当天的训练内容
3. 切换侧边栏到 **体重跟踪**，添加体重记录查看趋势

## 数据说明

- 数据仅存储在本机浏览器的 `localStorage` 中

- 清除浏览器数据或更换浏览器/设备会导致数据丢失

- 如需备份，可将浏览器中该域名下的 localStorage 数据导出
